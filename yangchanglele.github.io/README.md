## GitHub Pages 发布

1. 在 GitHub 账号 `yangchanglele` 下创建公开仓库 `yangchanglele.github.io`。
2. 将本目录中的 `index.html`、`styles.css`、`.nojekyll` 和 `README.md` 放到仓库的 `main` 分支根目录。
3. 打开仓库的 **Settings → Pages**。
4. 在 **Build and deployment** 中选择 **Deploy from a branch**，分支选择 **main**，文件夹选择 **/(root)**，点击 **Save**。
5. 等待发布完成，并打开 `https://yangchanglele.github.io/` 检查页面。

发布完成后，可将该完整主页地址填写到 OpenReview 的 **Homepage URL** 字段。请确保主页展示的邮箱与你注册 OpenReview 时使用的邮箱一致。

此说明本身不代表网站已经上线；以上线页面及仓库的 Pages 状态为准。
